# Network Topology Understanding Agent

OrcaRouterを利用して、**ネットワーク構成図をAIに読み込ませ、ネットワークの構成を理解させる機能**です。

## 概要

ネットワーク構成図をPDFとして入力すると、AIが構成図を解析し、ルーターやスイッチなどのネットワーク機器と、それらの接続関係を構造化します。

これにより、構成図を人が一つずつ確認するのではなく、AIがネットワークの構成を把握した状態で質問に回答できるようにします。

## 使用ライブラリ

依存ライブラリは `requirements.txt` に記載しています。

主なライブラリ：

- `openai` - OrcaRouter APIとの接続
- `pymupdf` - PDFの読み込み・画像化
- `pillow` - 画像処理
- `python-dotenv` - APIキーの環境変数管理
- `pydantic` - データ構造の定義

## 処理の流れ

```text
ネットワーク構成図（PDF）
        ↓
PDFからテキスト・画像を抽出
        ↓
Vision AIで構成図を解析
        ↓
ネットワーク機器・接続情報を抽出
        ↓
JSON形式で構造化
        ↓
AIがネットワーク構成を理解
        ↓
構成について質問・確認
```

## 認識できる情報

構成図から以下のような情報を抽出します。

* ネットワーク機器

  * Router
  * Switch
  * Server
  * PC
  * Firewall
  * Cloud
* 機器の名称・ラベル
* インターフェース名
* IPアドレス
* 機器同士の接続関係
* ネットワークセグメント
* GREトンネルなどの特殊な接続

抽出した情報は、ネットワークトポロジーとしてJSON形式に構造化します。


## OrcaRouterの利用

AIへの問い合わせには[OrcaRouter](https://www.orcarouter.ai/ja)を利用しています。

構成図の解析ではVision対応モデルを使用し、画像からネットワーク機器や接続関係を読み取ります。

その後、構造化されたネットワーク情報をAIに渡すことで、ネットワーク構成について質問できるようにしています。

##　使用モデルの変更

本プログラムは、画像を認識するモデルと質問をするモデルを別々に指定でき、コストを調整可能です。
orca_client.pyの31,32行目のVISION_MODELとREASONING_MODELにてモデルを指定する事が出来ます。
VISION_MODELは画像認識をする為、性能の高いモデルがお勧めです。

## 使用例

例えば、構成図を読み込ませた後に以下のような質問ができます。

```text
HQ-CORE-R1はどの機器と接続していますか？

BR1-EDGE-R4のGi0/1はどこにつながっていますか？
```

AIは構成図から抽出したトポロジー情報をもとに回答します。

## プロジェクトでの位置づけ

この機能は、ネットワークをAIが理解するための**構成理解部分**を担当します。

```text
┌─────────────────────────────┐
│      Network AI System      │
│                             │
│  ┌───────────────────────┐  │
│  │ Network Topology      │  │
│  │ Understanding         │  │
│  │                       │  │
│  │ PDF → AI → Topology   │  │
│  └───────────────────────┘  │
│              ↓              │
│       構造化された           │
│       ネットワーク情報       │
│              ↓              │
│        他の機能へ            │
└─────────────────────────────┘
```

本機能では、ネットワーク構成図から**「ネットワークがどのような構成になっているか」をAIが理解できる状態にすること**を目的としています。

## 特徴
コストパフォーマンス:orcarouter/autoで安いモデルを自動選択、画像読み取りのみ高精度モデルを使用
信頼性・堅牢性:try/exceptでエラー時もクラッシュせずループ継続、JSON抽出失敗時も部分データを保持
自律性:AIがPDFを自力で読んでトポロジーを認識、人が定義しなくてもノード・リンクを抽出
