# 実装範囲と残る制約

[プロジェクト紹介](../README.md) / [ドキュメント一覧](README.md)

この提出版は、Linuxの模擬ネットワーク上で、限定した障害シナリオの調査から業務復旧までを実演するものです。
実装・実測済みの根拠は[評価ガイド](evaluation/README.md)と[審査5項目との対応](judging.md)から参照できます。

## 対象範囲

- 実機・マルチベンダー機器への接続は対象外です。ネットワーク名前空間とnftablesによるLinux環境を使います。
- 冗長化制御は自作デーモンです。BGPやVRRPを実装したものではありません。
- 変更できる操作は、予備経路の限定した通信ルールの削除です。任意のネットワーク設定を自動修復するものではありません。
- PDFの解析結果は登録構成と照合します。不一致がある図を取り込んで、任意の新しい構成へ自動対応する機能ではありません。

## セキュリティ・評価の読み方

`APPROVAL_TOKEN`を設定しない直接起動は、認証なしの開発モードです。
`demo.sh`では操作トークンを生成しますが、組織のアカウント認証・役割管理を備えた本番運用基盤として検証したものではありません。

計画ハッシュは計画本体から生成し、案件IDは含みません。案件間の取り違えは別途計画IDとの照合で防いでいます。
ゲートウェイ側のファイアウォールは監視のみのシャドーモードです。監視記録と実際の操作拒否を区別してください。
防御ごとの範囲と未対応事項は[OWASP対応表](security-owasp.md)にあります。

モデルの選択結果・費用・所要時間は、測定日時と条件に依存します。
攻撃検証で拒否できた入力があることは、あらゆる攻撃を防げることの証明ではありません。
構成図からの調査と引き継ぎを一案件で扱う設計の価値は、利用者を交えた効果検証とは分けて説明します。
